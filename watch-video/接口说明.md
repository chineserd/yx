# 观看视频接口说明

接口草稿 · V0.1 · 更新日期 2026-11-23 · **建议草稿，待研发确认**

本文件定义教研上传发布、学生观看选择、后台 UV/PV 查询所需的接口行为。路径、字段名和状态码为建议值；权限、人群及完成口径以 [PRD](PRD.md) 的待确认事项为准。当前原型使用浏览器本地状态，尚未与真实服务联调。

## 1. 接口清单与共用约束

| 编号 | 关联需求 | 能力与调用方 | 建议方法和路径 | 状态 |
| --- | --- | --- | --- | --- |
| API-01 | FR-01、FR-04 | 后台／App 查询视频列表与详情 | GET /api/study-videos；GET /api/study-videos/{videoId} | 新增草稿 |
| API-02 | FR-01 | 后台上传片段并查询处理结果 | POST /api/study-videos/uploads；GET /api/study-videos/uploads/{uploadId} | 新增草稿 |
| API-03 | FR-02、FR-03 | 后台保存草稿／发布／下架 | PUT /api/study-videos/{videoId}/draft；POST /api/study-videos/{videoId}/publish；POST /api/study-videos/{videoId}/archive | 新增草稿 |
| API-04 | FR-05、FR-06、FR-07 | App 建立播放会话并更新进度 | POST /api/study-videos/{videoId}/play-sessions；PUT /api/study-videos/{videoId}/play-sessions/{sessionId}/progress | 新增草稿 |
| API-05 | FR-08 | App 提交选择 | POST /api/study-videos/{videoId}/play-sessions/{sessionId}/choices | 新增草稿 |
| API-06 | FR-06、FR-07、FR-09 | 后台查统计、选择和学生明细 | GET /api/study-videos/{videoId}/statistics；GET /api/study-videos/{videoId}/events | 新增草稿 |

**鉴权和范围**：全部请求使用现有登录态，服务端从登录态取得 accountId、studentId、角色和学校范围，不接受前端自报身份作为授权依据。后台仅教研授权角色可写；学生端仅能读取对本人可见的已发布内容并写本人学习事件。学生账号关联多学员时，调用方应传选中的 studentId，并由服务端核对归属。学校、课程和班级权限具体来源待研发确认。

**响应包装建议**：成功返回 `{ "code": "OK", "data": ... }`；失败返回 `{ "code": "ERROR_CODE", "message": "可展示的原因", "requestId": "..." }`。数值 0 是有效结果，不使用 null 表示 0。时间传 ISO 8601，统计查询的日期按北京时间自然日闭区间解释。分页默认 page=1、pageSize=10，上限由研发确认。

## 2. API-01 查询视频

**请求**：`GET /api/study-videos?view=admin|student&courseId=&status=&keyword=&page=1&pageSize=10`；详情 `GET /api/study-videos/{videoId}`。后台列表允许状态与名称筛选；App 调用时由服务端固定过滤已发布及可见范围，不能用 `view=admin` 绕过权限。App 在课件页进入时传 courseId；课程绑定规则待确认。无 body。详情须返回当前可见版本的片段及选项，学生端不得返回草稿或内部审核字段。

| 字段 | 位置／类型 | 必填与规则 |
| --- | --- | --- |
| videoId | path／string | 详情必填，稳定视频 ID |
| view | query／enum | 列表必填，admin 或 student；服务端复核角色 |
| courseId | query／string | App 课件页建议必填；正式绑定规则待确认 |
| status、keyword | query／string | 后台可选；keyword 去首尾空格 |
| page、pageSize | query／integer | 默认 1、10；均为正整数 |

**返回**：列表 `data.items[]` 含 videoId、title、description、coverUrl、status、publishedAt、segmentCount、version；`data.total` 为整数，可为 0。详情另含 startSegmentId、segments[]（segmentId、title、durationSeconds、playUrl、options[]），选项含 optionId、text、targetSegmentId；结局片段 options 为空数组。

**异常与保存影响**：未登录 401；无权限或不可见 403；视频不存在 404；下架内容对学生返回 404，对教研保留可查询。查询不改数据。联调验收：学生请求草稿或跨学校视频不可见；空列表返回 items=[]、total=0。

## 3. API-02 上传与处理

**请求**：`POST /api/study-videos/uploads`，multipart/form-data，file 必填（视频二进制），videoId 可选，clientRequestId 必填用于重试去重。后台上传文件后调用 `GET /api/study-videos/uploads/{uploadId}` 查询处理状态。格式、容量、时长、转码清晰度由研发确认后落实到服务端校验和页面提示。

| 返回字段 | 类型／含义 |
| --- | --- |
| uploadId | string；上传任务 ID |
| status | enum；uploading、processing、ready、failed |
| mediaId | string 或 null；ready 时必有 |
| durationSeconds | number 或 null；ready 时必有，可为有效 0 的规则待研发确认 |
| reason | string 或 null；failed 时说明原因 |

**成功示例**：

```json
{"code":"OK","data":{"uploadId":"up_101","status":"processing","mediaId":null,"durationSeconds":null,"reason":null}}
```

**失败示例**：

```json
{"code":"INVALID_MEDIA","message":"视频格式不支持","requestId":"req_101"}
```

**异常与保存影响**：文件过大、格式不支持返回 400；上传中断允许重试并以 clientRequestId 去重。处理失败保留草稿与原有片段，不创建可发布媒体；发布接口二次校验 ready。联调验收：失败上传可重试且不会产生两个片段引用。

## 4. API-03 草稿、发布与下架

**请求**：`PUT /api/study-videos/{videoId}/draft` 保存标题、简介、课程范围及完整片段图；`POST /api/study-videos/{videoId}/publish` 发布当前草稿；`POST /api/study-videos/{videoId}/archive` 下架。创建时 videoId 可为客户端临时 ID 或另设创建接口，待研发定案。写请求带 `If-Match` 内容修订号，防止覆盖他人修改；发布和下架带 clientRequestId 防重复提交。

| 草稿字段 | 类型／必填与校验 |
| --- | --- |
| title、description | string；title 必填且最多 100 字，description 可空、最多 300 字 |
| courseId | string 或 null；原型绑定课程，正式规则待确认 |
| startSegmentId | string；发布必填，必须命中片段 |
| segments[] | array；发布时至少 1 项；每项 segmentId、title、mediaId、options[] |
| options[] | array；每项 optionId、text、targetSegmentId；文案非空、不重复，目标存在 |

**返回**：保存返回 videoId、revision、status=draft；发布返回 videoId、version、publishedAt、status=published；下架返回 videoId、status=archived。写入需原子完成，发布前检查媒体 ready、全部跳转目标及从开场到结局的可达路径；发布失败不改变学生可见版本。已发布视频重新编辑时保留旧版本供历史事件归属，具体续看策略待确认。

**成功示例**：

```json
{"code":"OK","data":{"videoId":"vid_001","version":2,"publishedAt":"2026-11-23T14:30:00+08:00","status":"published"}}
```

**失败示例**：

```json
{"code":"INVALID_BRANCH","message":"片段“背景”的选项缺少跳转目标","requestId":"req_102"}
```

**异常与保存影响**：缺字段或分支不合法 400，媒体未 ready 409，修订冲突 409，无权限 403。前端保留编辑内容，定位字段并允许修正；未保存离开由前端提示，取消不写服务端。联调验收：草稿不出现在学生列表；缺目标发布失败；重复发布不生成重复版本；下架后历史事件仍可查。

## 5. API-04 播放会话与进度

**请求**：学生实际点击播放时调用 `POST /api/study-videos/{videoId}/play-sessions`，body 含 studentId、contentVersion、clientRequestId。服务端校验身份与可见性，按 clientRequestId 幂等建立 sessionId，并记录一次有效播放开始，计入 PV。暂停后继续或同会话片段跳转不再调用新建会话。进度使用 `PUT /api/study-videos/{videoId}/play-sessions/{sessionId}/progress`，body 含 segmentId、positionSeconds、completedCandidate、sequence。

**返回**：新建会话返回 sessionId、studentId、contentVersion、startedAt、resumeSegmentId、resumePositionSeconds；进度返回 acceptedSequence、savedAt。positionSeconds 为非负数且不能超过片段时长；sequence 为会话内递增整数，旧序号请求不覆盖较新进度。

**成功示例**：

```json
{"code":"OK","data":{"sessionId":"sess_001","studentId":"stu_001","contentVersion":2,"startedAt":"2026-11-23T14:35:00+08:00","resumeSegmentId":"seg_01","resumePositionSeconds":0}}
```

**失败示例**：

```json
{"code":"VIDEO_UNAVAILABLE","message":"当前视频暂不可观看","requestId":"req_103"}
```

**异常与保存影响**：无权限 403、下架或版本不可用 409、会话不存在 404；网络失败时前端保留本地进度并重试，同一 clientRequestId 不重复增加 PV。UV 在查询期内按 studentId 去重；时间归属由 startedAt 的北京时间日期决定。多设备进度合并和正式完成口径待产品确认。联调验收：首次播放 PV+1、暂停继续 PV 不变、退出后重进并重新播放 PV+1，同学生 UV 不变。

## 6. API-05 提交选择

**请求**：`POST /api/study-videos/{videoId}/play-sessions/{sessionId}/choices`，body 含 segmentId、optionId、clientRequestId。服务端依据该会话的 contentVersion 验证选项与目标，返回 targetSegmentId、chosenAt、eventId；不得信任客户端自报的目标片段。相同 clientRequestId 重试返回同一 eventId，前端只跳转一次。

**成功示例**：

```json
{"code":"OK","data":{"eventId":"choice_001","targetSegmentId":"seg_repair","chosenAt":"2026-11-23T14:35:18+08:00"}}
```

**失败示例**：

```json
{"code":"OPTION_NOT_FOUND","message":"当前选项已不可用，请重新进入视频","requestId":"req_104"}
```

**异常与保存影响**：无权限 403，选项与版本不符 409，重复但请求键不同的同一片段选择应按会话与片段状态校验，防止重复选择。成功事件保留 studentId、videoId、contentVersion、segmentId、optionId、targetSegmentId、chosenAt 和 sessionId。联调验收：一次选择产生一条记录，失败不跳转，重试不重复写入。

## 7. API-06 观看统计与明细

**请求**：教研调用 `GET /api/study-videos/{videoId}/statistics?from=2026-11-23&to=2026-11-23`；明细调用 `GET /api/study-videos/{videoId}/events?from=&to=&page=1&pageSize=10`。from、to 为北京时间日期，含起止日；from>to 返回 400。服务端按教研学校与可查看范围过滤，学生端无权调用。

**返回**：statistics.data 含 videoId、from、to、uv（去重 studentId）、pv（有效播放开始数）、choiceCount（选择事件数）、openingOptions[]（optionId、text、count）。events.data 含 total、items[]；每项为 studentId、studentName、eventType、videoVersion、sessionId、segmentId、optionId 或 null、occurredAt。无记录返回 0 和空数组，非 null。

**成功示例**：

```json
{"code":"OK","data":{"videoId":"vid_001","from":"2026-11-23","to":"2026-11-23","uv":2,"pv":3,"choiceCount":2,"openingOptions":[{"optionId":"opt_find","text":"先去找丢失的羊","count":1},{"optionId":"opt_fix","text":"立即修补羊圈","count":1}]}}
```

**失败示例**：

```json
{"code":"INVALID_DATE_RANGE","message":"开始日期不能晚于结束日期","requestId":"req_105"}
```

**异常与保存影响**：无权限 403、日期错误 400、查询失败 500；前端显示失败并提供重试，不把失败显示成 0。查询不写数据，统计与明细使用同一事件源及日期范围。联调验收：同学生两次播放、另一学生一次播放，UV=2、PV=3；空期 UV/PV/choiceCount 均为 0；开场选择次数和明细可对齐。

## 8. 接入与待确认

- 当前静态原型用预置故事与浏览器本地状态演示流程，未连接真实转码、登录身份、数据库或事件服务；原型数据不作为线上统计证据。
- 正式路径、请求包装、媒体存储、分页上限、上传限制和错误码由研发确认。建议字段不等于已存在接口。
- 发布对象、课程绑定、完成判定、下架时继续播放、已发布内容改版与旧版续看规则由产品、教研、研发确认后，同步修订 PRD 与本接口文档。
