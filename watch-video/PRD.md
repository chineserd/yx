# 观看视频

PRD · V0.2 · 更新日期 2026-11-23

教研在后台上传多条视频，学生从中文路 App 首页进入视频汇总页观看学习。后台按视频查看观看 UV、PV 与观看记录，学生在列表中查看自己的观看状态。

## 1. 涉及端口 · 菜单 · 功能点

1. 中文路后台／教研端｜内容管理 → 视频
   上传视频文件并填写名称、备注；按视频和日期查看观看 UV、PV 与观看记录。
2. 中文路 App／学生端｜首页 → 视频 → 视频汇总页 → 播放页
   浏览视频、播放和续看，查看“未观看／观看中／已看完”状态；学生不上传内容。

## 2. 后台上传与观看数据

- 教研每次上传一条视频：选择视频文件，填写视频名称和备注。重复上传可形成多条视频列表。上传与处理成功后，视频出现在后台列表和学生视频汇总页；失败时保留已填内容、显示原因并允许重试。正式文件格式、大小和时长上限由研发确认后在上传前提示。
- 后台只有“视频”一个业务菜单页面。列表展示视频名称、备注、上传时间、观看 UV、观看 PV，以及“查看数据”；数据页按北京时间日期范围查询该视频的 UV/PV 与观看记录。统计无记录时显示有效 0，查询失败时显示失败及重试入口。
- **观看 UV**：所选日期范围内，实际开始播放该视频的去重学生数。同一学生跨设备或多次观看，只计 1 人。
- **观看 PV**：所选日期范围内，该视频实际开始播放的次数。首次播放、播放完成后重播、离开后再次进入并播放分别计数；同一次观看中的暂停后继续不重复计数。
- 打开首页、视频汇总页或播放页但没有播放，不计入 UV/PV。统计以学生 ID 去重，按播放开始时间归入北京时间日期。
- 每次实际开始播放形成一条观看记录。记录展示**学生、学生编号、观看的视频内容、观看时长、观看开始时间**；观看时长累计本次播放实际发生的时间，暂停期间不累计。观看记录不展示片段、选项、行为类型或内容版本。

## 3. 学生 App

- 首页沿用中文路 App 现有布局，在首页增加“视频”总入口。点击进入“视频”汇总页，展示所有对当前学生可见且已处理完成的视频；不要求先进入课表或课程。无视频时显示空态并可返回首页。
- 视频卡展示封面、名称、时长和当前学生的观看状态：**未观看**（没有播放记录）、**观看中**（已开始但未播完）、**已看完**（至少一次播放到结尾）。状态按学生和视频分别保存，不能用全体学生的 UV/PV 代替个人状态。
- 点击视频进入播放页，支持播放、暂停、继续、从头播放和返回。离开后保存进度；再次进入可续看。播放到结尾后状态变为“已看完”，可重播或返回视频汇总页；重播不清除已看完状态。播放失败保留进度并提供重试。
- 学生端没有上传、编辑、片段分支或选择题。

## 4. 示例

学生甲首次打开《亡羊补牢》但没有播放，状态为“未观看”，UV=0、PV=0。开始播放后状态为“观看中”，UV=1、PV=1；暂停后继续，PV 不变。播放到结尾后状态为“已看完”；再次进入重播后，UV 仍为 1、PV 变为 2。

## 5. 功能需求与验收

| 编号 | 操作与可观察结果 | 状态 |
| --- | --- | --- |
| FR-01 | 教研填写名称、备注并选择视频文件，成功后后台多条视频列表和学生视频汇总页可见 | 待验收 |
| FR-02 | 上传失败显示原因并可重试，未处理完成的视频不在学生端展示 | 待验收 |
| FR-03 | 首页“视频”入口进入汇总页；汇总页可进入播放页并返回 | 待验收 |
| FR-04 | 未播放、播放中、播完分别显示“未观看／观看中／已看完”；退出续看与重播后状态正确 | 待验收 |
| FR-05 | 同一学生首次播放、暂停继续、再次进入播放后，UV=1、PV=2 | 待验收 |
| FR-06 | 两名学生共播放三次时 UV=2、PV=3；空日期范围 UV/PV 均为 0 | 待验收 |
| FR-07 | 每次播放形成一条观看记录，列出学生、编号、视频内容、实际观看时长和开始时间；不出现版本与片段列 | 待验收 |

## 6. 待确认事项

1. **视频可见范围**：所有学生可看，还是按班级、课程或人群控制？由产品与教研确认。
2. **上传限制**：支持格式、文件大小、最长时长及转码失败重试规则由研发确认。
3. **有效播放阈值**：是否播放满一定时长才计入 UV/PV？当前按实际开始播放计数，由产品确认。
4. **多设备续看**：同一学生在多个设备观看时，以哪次进度为准？由产品与研发确认。
