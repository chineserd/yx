## 二、本项目命令

在项目目录执行：

```bash
npm run check
git diff --check
```

其中 `npm run check` 包含 Pages 构建和作文题库相关自动测试。

只修改 Vue 页面时，可额外执行：

```bash
npm run check:vue
```

需要源码热更新时：

```bash
npm run dev -- --host 0.0.0.0 --port 4173
```

## 三、本项目重点走查范围

- 默认进入“发布任务”页面，保留“发布任务”和“任务管理”核心流程。
- “自定义作文题目”和“选择已有题目”分支的入口、下一步行为和后续页面不同。
- 作文题库抽屉的搜索、筛选、滚动、长题目展示、分类对齐和选择确认。
- 任务管理表格的首行和操作列固定，滚动时不能重叠或被遮挡。
- 顶部导航、侧边菜单、需求标识、PRD和验收清单入口保持一致。
- 不恢复已移除的旧批量导入入口和相关弹窗逻辑。
