作文寫後指導

PRD · V0.4 · 更新日期 2026-11-24待評審

教師在發佈作文任務時開啟寫後指導。學生完成初稿並收到批改後，逐條處理修改意見，形成修改後的文章。

涉及端口 · 菜單 · 功能點

  1. 教師後台｜發佈任務 → 任務設置 → 功能配置

    按任務開啟「寫後指導（可選）」，與寫前指導並列。

  2. 教師後台｜任務管理 → 寫後作文／任務詳情

    在任務列表、成績概覽及學生答題情況中查看寫後指導的開啟狀態與處理進度。

  3. 教師後台｜學生答題情況 → 學習作文報告 → 寫後指導

    頂部「寫後指導」Tab 內使用左右聯動工作區：左側顯示合成後作文，右側逐條顯示批改意見、原文、修改後內容和學生「已修改／已忽略」狀態。

  4. 啟達平板學生端｜教師任務 → 作文批改報告 → 寫後指導

    此入口路徑為待評審方案；學生逐條修改、忽略或確認意見，再完成文章。

業務規則

任務開關與聯動展示

  1. R00 發佈配置

    「寫後指導」是單個作文任務的可選開關，默認關閉；教師發佈任務時保存開關值。

  2. R01 任務管理列表

    任務管理增加「寫後作文」Tab，展示開啟寫後指導的作文任務。任務行需要呈現寫後指導狀態及進度；具體列名、篩選條件與狀態名稱待確認。

  3. R02 成績概覽

    開啟寫後指導的任務，在「寫前指導完成」旁增加「寫後指導完成」進度卡，標題、數字格式及「已完成 X 人」說明沿用寫前指導卡。示意值為 12 / 30；分子何時增加、分母是否始終為任務學生數待確認。

  4. R03 學生答題情況

    開啟寫後指導的任務，在學生表格增加「寫後指導」列，逐人展示「未完成／已完成」等處理狀態。關閉時不展示寫後指導專屬列及進度卡。

  5. R04 教師報告分層

    在「學習作文報告」頂部，與「寫前指導」「作文批改報告」並列顯示「寫後指導」Tab。Tab 內不設子 Tab：左側把學生已修改的片段合成作文，已忽略的意見保留原文；右側逐條展示原文、批改意見、修改後內容或忽略結果、已修改／已忽略狀態。左右對應片段以可見連線與點擊定位聯動。學生完成與提交時點、空態和圖片版呈現仍待確認。

學生端處理意見

  1. R05 查看意見

    學生在已開啟任務的作文批改完成後，查看與原稿對應的寫後指導意見；未開啟任務不出現該功能入口。具體入口仍待評審。

  2. R06 逐條處理

    每條意見提供「修改」「忽略」「確認」操作。「修改」用於調整相應作文內容；「忽略」表示本次不採納；「確認」表示該條意見的處理已定。操作順序、能否撤回及未修改時能否直接確認待確認。

  3. R07 完成文章

    學生根據已完成修改並確認的意見形成修改後的文章；忽略的意見保留處理記錄。修改稿的編輯、保存、提交及與初稿的版本關係待確認。

示例

教師發佈給 2A 班的作文任務時開啟寫後指導。任務進入「寫後作文」Tab；學生完成初稿並收到批改後，處理各條意見。任務詳情示意顯示「寫後指導 12/30」，學生表格可見逐人「未完成／已完成」。12/30 僅表示展示位置與格式，完成口徑待確認。

功能需求與驗收

編號操作與預期結果狀態
R00發佈作文任務時可勾選寫後指導；默認未勾選，發佈後保留該任務的開關值。待驗收
R01任務管理切換「寫後作文」Tab，可看到符合條件的作文任務及其寫後狀態。待驗收
R02開啟任務的成績概覽顯示寫後指導進度卡；關閉任務不顯示該卡。待驗收
R03開啟任務的學生表格逐人顯示寫後指導狀態；關閉任務不顯示該列。待驗收
R04開啟任務的單生報告可切換「寫後指導」；左側合成作文與右側逐條意見並排，已修改／已忽略狀態、修改後內容與連線對應正確。待驗收
R05已開啟任務完成批改後，學生可查看與原稿對應的寫後指導意見。待驗收
R06學生對一條意見操作修改、忽略或確認後，該條展示對應處理結果。待驗收
R07學生完成意見處理後，可形成並查看修改後的文章。待驗收

待確認事項

  1. 「寫後作文」Tab 是獨立任務分類，還是「命題作文」的篩選視圖？任務列表的寫後狀態與進度列如何命名？
  2. 寫後指導 12/30 的分子以「已確認全部意見」「已提交修改稿」還是其他節點計數？分母是否為任務學生總數？
  3. 學生表格的「未完成／已完成」如何判定？未開始、修改中、全部忽略、部分意見未處理如何展示？
  4. 學生從作文報告進入寫後指導是否合適？是否復用現有「批改記錄」列表？
  5. 「修改／忽略／確認」的準確順序、撤回規則及保存方式是什麼？如何處理同一原文片段上的多條意見？
  6. 修改後的文章由學生全文編輯、逐條替換生成，還是拍照上傳？何時算完成，能否再次提交？
  7. 左右聯動的寫後報告是否展示處理時間、是否提供圖片版／初稿對照、是否重新評分？未處理意見與同一片段多條意見如何展示？
  8. 教師、AI 各自提供哪些寫後指導內容？
  9. 開關與學生自助上傳／教師統一上傳、「顯示成績和報告」的關係，以及已發佈任務能否更改開關？
