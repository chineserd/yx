# 考点管理 PRD

考点关联已有标签。中文路后台和普通话科后台可按考点筛选，学生端在练习卡展示考点。

## 一、需求概览与范围

现有标签用于题目分类，但不能直接代表考点。本需求新增独立考点，**不改动标签层级、名称和题目原标签**。

| 序号 | 需求 | 说明 |
| --- | --- | --- |
| 1 | 中文路后台增加考点管理 | 新增、编辑和维护考点，关联已有标签；港澳题库展示并筛选考点。 |
| 2 | 历史标签数据对应考点 | 按映射给现有约 9000 道题目及相关数据自动补考点，保留原标签；后续数据沿用最新映射。 |
| 3 | 普通话科试卷库考点与筛选 | 试卷库展示已关联的考点，支持多选考点和按创建日期筛选。 |
| 4 | 学生端展示考点标签 | 在对应练习中显示考点标签。 |
| 5 | 考点与试题的关联关系 | 一个考点可关联多个已有标签；一道试题可关联多个考点。 |

首批拟配置零聲母、平翘舌、前后鼻音、人名拼写规则、地名拼写规则、声调变调。零聲母关联已有标签 y、w；其他考点的具体标签由运营选择。优先满足中学需求；海外题库不在本次范围。

## 二、业务流程

1. **中文路后台配置**：新增或编辑考点，关联已有标签并保存。
2. **历史数据回填**：读取存量题目和数据的原标签，按当前映射自动补上考点；原标签保留。
3. **后续关联**：新增考点、调整映射或新增带标签的数据时，按最新有效映射关联相应题目和数据。
4. **多端展示**：港澳题库与普通话科试卷库展示、筛选已配置考点；App 从学习首页进入年级选择页，选择年级后在对应练习展示考点标签。人工修改保存后以修改后的结果为准。

## 三、关联与管理规则

| 事项 | 规则 |
| --- | --- |
| 数据关系 | 考点是独立对象。一个考点可关联多个已有标签，同一标签也可关联多个考点；一道试题可关联多个考点，同一考点也可关联多道试题。不设置“所属业务模块”字段。 |
| 匹配 | 题目标签命中考点的**任一启用标签**即关联该考点。选择父级标签时展开子级；父子重复选择去重。 |
| 生效 | 新增、编辑或导入考点后同步触发关联计算；列表的关联题目数按当前有效关系统计，包含历史自动回填结果。 |
| 校验 | 名称必填且全系统唯一；至少关联一个有效标签；不允许选择已停用标签。 |
| 标签变化 | 标签停用后不参与新增自动匹配；已有题目的原标签和已生成的考点关联继续展示、不清除。改名不改变关系；被考点引用的标签不可直接删除。 |
| 考点删除 | 已关联题目的考点不可删除；未关联题目的考点可删除。 |
| 人工调整 | 自动匹配先生成考点关联；运营在题目编辑页修改并保存后，以修改后的考点为准，列表展示、筛选及关联题目数同步使用该结果。 |

## 四、页面要求

### 後台－中文路

- **考点管理**与港澳题库同级。列表展示名称、关联标签数、关联题目数、创建人、创建时间和操作；默认按创建时间倒序。支持名称、创建人、标签、时间筛选，以及新增、编辑、删除、批量导入。
- 新增／编辑页配置名称、关联标签和备注；沿用现有「拼音标签」层级（如「声母-双唇音 → b／p／m」）搜索、展开和多选，勾选父级时关联其下级标签。已选标签按类别分组，区域限高滚动，可逐项移除或清空。
- **港澳题库**在题目列表、筛选和编辑页增加考点。列表移除“序号”“审核状态”，对应筛选及新增试题表单也不展示这两个字段；保留原标签字段。新增或编辑题目可直接选择考点。
- **海外题库**不显示本需求标志，点击该原型侧栏入口不切换页面。

### 後台－普通話科

「聆聽與拼音／試卷庫」列表展示原有试卷、标签及已关联考点。筛选区首行为「試卷標題」「難度」「類型」，第二行为「考點」「標籤」「創建人」，第三行为「創建時間」「查詢」「重置」。「考點」支持多选，试卷命中任一个所选考点即可入选。「創建時間」按起止日期查询，包含开始和结束当天。考点、日期与其他已填条件共同生效，点击「重置」清空筛选。侧栏入口、新增筛选项和新增考点表头标示「需求」。

### 學生端（App）

学习首页点击「拼音練習」进入年级选择页，选择 P1–P6 或 S1–S6 后进入练习列表。列表左上是返回按钮，下一行左侧是标题，右侧并排显示浅蓝色的年级和「歷史記錄」按钮。点击年级按钮可重新选年级。列表返回年级页，再返回学习首页并恢复原滚动位置。

练习卡上下两行分别展示考点与原有标签，多个值可换行。零聲母关联 y、w，平翹舌关联 z、c、s、zh、ch、sh、r，练习 4 同时关联變調和前後鼻音。首张卡片保留一个「需求」标志。手机预览保持 430px 逻辑宽度，外层手机按窗口等比缩放并完整入屏。「學習／任務」底部导航只在学习首页显示。

## 五、批量导入

支持 Excel 批量新增或更新考点。模板字段为**考点名称、关联标签**；标签路径用 `/` 分隔层级，多个标签用英文逗号分隔。导入时执行名称唯一、标签有效性校验，保存后触发关联计算。

## 六、验收要点

- 可新增、编辑考点；未关联题目时可删除，已关联题目时不可删除。名称和标签校验生效，父级标签展开后正确去重；大量已选标签仍可查看、移除与清空。
- 历史题目按已有标签自动补考点，原标签保留；新增考点或映射变更后，相关数据和题目按新关系更新；一个考点可关联多个标签，一道试题可关联多个考点。
- 人工修改考点并保存后，港澳题库和普通话科试卷库展示、筛选及关联题目数以修改后的结果为准；海外题库不纳入。
- 普通话科试卷库多选考点后显示命中任一所选考点的试卷，可与创建日期范围组合查询。重置后恢复当前试卷库范围内的全部数据。
- 学生端从首页进入年级选择页，选择 P1–P6 或 S1–S6 后列表显示所选年级。可重新选年级或返回首页，返回时恢复首页滚动位置。练习卡按上下两行展示考点与原有标签，支持显示多个考点。
- 停用标签后，已有标签数据及考点关联继续展示；导入后能建立关联。
