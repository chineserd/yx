# 前后台字段核对
V0.9 · 2026-10-28

## 班主任统计
筛选：问卷、班主任姓名搜索、提交日期（含首尾，北京时间）。列表：班主任、答卷数、服务满意率（列表仅展示百分比）、查看答卷。页首汇总按总体服务满意率、班主任数、答卷数顺序展示；不增加排名。“服务满意率”表头旁提供说明图标，默认隐藏，点击显示统计题、满意率公式、分母排除规则及计算举例（12份有效评价：5份非常满意、4份满意、2份一般、1份不满意，满意率为75.0%）；点击关闭或说明浮层外部可收起，不在指标下方常驻显示。

编辑问卷不展示统计题选择与选项归类配置；系统按标准班主任服务题及五档选项自动识别，详见PRD。答卷记录保留班主任搜索，支持从统计页带入。

## 1. 问卷管理列表
| 字段 | 展示及来源 |
| --- | --- |
| 问卷名称 | 当前问卷名称 |
| 发送状态 | 已启用／已停用 |
| 每日发送时间 | 当前配置，北京时间 |
| 答卷数 | 该问卷的成功提交总数 |
| 更新时间 | 最近保存或启停的时间，完整年月日时分 |
| 操作 | 查看、编辑、复制、查看答卷、启用／停用 |

筛选：问卷名称模糊查询、发送状态。新增问卷填写后保存为停用状态，取消不生成列表记录。

## 2. 问卷编辑及查看抽屉
| 字段 | 类型 | 约束与展示 |
| --- | --- | --- |
| 问卷名称 | 文本，必填 | 后台识别，最多100字 |
| 问卷标题 | 文本，必填 | 问卷填写页展示，最多100字；不作为邀请弹窗或系统推送标题 |
| 问卷说明 | 多行文本，选填 | 最多500字；在问卷填写页标题下展示，用于作答提示，不重复邀请文案 |
| 题型 | 单选题／文本题 | 每题必选 |
| 题目 | 文本，必填 | 最多500字 |
| 选项 | 文本列表 | 单选至少2项、非空不重复；每项最多100字 |
| 是否必填 | 开关 | 每题独立设置 |
| 题序 | 上移／下移 | 第一题不可上移、末题不可下移 |
| 文本题字数 | 固定500字 | 不新增配置字段 |
| 发送对象 | 多选，必填 | 在读用户／进入复购跟进的学生，至少选一类；默认两类均选 |
| 已上正式课次数 | 数值输入，必填 | 默认3，整数≥1；仅选择在读用户时校验，展示“已上正式课次数≥N次” |
| 复购跟进剩余课次数上限 | 数值输入，必填 | 默认10，整数≥0；仅选择复购跟进学生时校验，展示“剩余正式课次数≤N次” |
| 每日发送时间 | 时间，必填 | HH:mm，北京时间，保存后生效；推送与邀请共用 |
| App 内弹窗 | 固定说明 | 课程结束后进入/回到App首页触发；距下一节课开课≤30分钟不弹（含恰好30分钟，无下一节课时不抑制）；按北京时间自然日关闭后当天不再弹，次日未完成再提醒；不提供独立开关 |
| App 推送 | 开关 | 仅控制是否发起推送；用户通知权限与设备状态决定实际展示，关闭不影响App内弹窗 |
| 通知标题 | 文本，条件必填 | 勾选“App 推送”后展开并必填，最多30字；关闭推送时折叠隐藏，已填写值保留且不校验；不用于App内邀请弹窗 |
| 通知内容 | 多行文本，条件必填 | 勾选“App 推送”后展开并必填，最多100字；关闭推送时折叠隐藏，已填写值保留且不校验；不用于App内邀请弹窗 |
| 点击去向 | 固定只读 | 本次邀请对应问卷，不配置任意外链 |

通知设置在查看抽屉中仅展示App内弹窗与App推送状态，省略点击去向、通知标题和通知内容；系统推送文案仅在编辑页配置。当前不设计App内独立通知中心。

查看抽屉只展示当前内容，不提供版本选择；已有答卷时编辑锁定题目及统计口径。编辑底部为“取消、保存”。

“通知设置”为发送设置下的子分组，共用发送对象和每日发送时间，不增加独立菜单。

发送设置标题右上角提供“规则说明”，默认收起，点击展开或收起人群并集、类内状态与课次条件、北京时间、下一时刻生效、学生/问卷去重及停用规则。编辑和只读详情共用说明，不改变已填字段。

## 3. 答卷记录列表与详情
列表字段：问卷名称、学生姓名/ID（同列上下两行）、班主任、总体满意度、班主任服务、教学质量、推荐意愿、其他建议、提交时间、查看。

四项评价直接展示所选答案，不满意/非常不满意及不愿意/非常不愿意使用红字。其他建议最多一行，超出以省略号截断，悬停展示全文，也可点击建议或查看进入详情；未填写显示“-”。宽表格局部横向滚动，操作列固定右侧。

“全部问卷”按标准五题显示；选定问卷后按该问卷实际题目生成评价列，标准题沿用简短列名，非标准题以题干为列名。每份答卷按填写快照匹配唯一相同题干及题型，不按题序取值；不匹配或缺失显示“-”，详情继续展示原题原答案。

筛选字段：问卷、班主任姓名搜索、学生姓名或ID、提交日期区间。班主任姓名支持模糊匹配，空值为全部；统计下钻使用精确归属。学生姓名模糊匹配，ID精确匹配；日期含首尾日，北京时间。日期倒置时提示纠正。

详情展示：问卷名称、提交时间、学生ID、学生姓名、提交时班主任、生成邀请时命中对象、每题题干与用户答案。选填未答显示“未填写”，无班主任显示“未分配班主任”。答案只读，不增加编辑功能。

## 4. 初始五题
| 编号 | 题干 | 类型及建议必填性 | 初始选项 |
| --- | --- | --- | --- |
| Q1 | 综合整体体验，您的总体满意度是？ | 单选，必填 | 非常不满意／不满意／一般／满意／非常满意 |
| Q2 | 日常服务和问题处理时效，您对班主任的服务是否满意？ | 单选，必填 | 同Q1五档选项 |
| Q3 | 结合课程内容和授课效果，您对整体教学质量是否满意？ | 单选，必填 | 同Q1五档选项 |
| Q4 | 您是否愿意向身边亲友推荐我们的课程？ | 单选，必填 | 非常不愿意／不愿意／不确定／愿意／非常愿意 |
| Q5 | 其他评价或建议 | 文本，选填 | 最多500字 |

题干来自用户需求；初始选项与必填性为建议，运营可编辑。App读取绑定版本的题目顺序、题型、题干、选项和必填性，不展示后台内部名称、版本及命中条件。

## 5. 服务端自动数据
学生ID与关联账号来自登录关系；在读、已完成正式课次、剩余课次及复购状态来自业务系统，具体字段待核实。0是有效课次，未知不按0处理；负课次需数据核查。两类人群独立判断，缺失一类数据不阻断另一类充分数据的判断。

页面不展示版本管理，服务端仍生成内部快照标识及问卷ID、稳定题目/选项ID、邀请ID、答卷ID及时间。邀请绑定问卷版本；答案绑定题目与选项ID，不能用数组序号替代身份。班主任采用提交时归属快照。原型样例以静态版本快照呈现，正式契约见接口说明。

## 后台布局密度
后台采用紧凑布局：页边距16×20px，Tab高52px，筛选区上下16px，统计卡片内边距12×16px，普通表格行高52px，含学生姓名/ID双行的答卷列表行高56px。保持正文字号，不改变字段、计算规则或App触控尺寸。

答卷列表横向滚动时，学生姓名/ID、班主任两列固定在左侧，操作列固定在右侧，表头与对应数据一起固定；问卷名称及评价内容随横向滚动，空结果提示不固定。

## 列表导出
班主任统计、答卷记录、问卷管理的筛选区提供“导出”按钮。导出当前已执行查询的全部匹配结果（不限当前页）；修改筛选输入后需先查询再导出。CSV使用UTF-8 BOM，可用Excel打开。导出包含列表业务字段，不含操作列及内部版本。学生姓名与ID分列，其他建议保留完整文本，空答案为“-”。统计导出复用页面满意率口径；无数据时提示“暂无可导出的数据”，不生成空文件。文本单元格转义引号、换行并防止公式执行。

## 后台视觉主题
采用《中文路后台系统设计规范》V1.0：深色侧栏、白色顶栏、蓝色选中标签与主操作、浅灰页面底、白色工作区、斑马纹表格及浅蓝悬停态。保留已确认紧凑间距、筛选、分页、导出及冻结列；App与原型顶部外壳不套用后台主题。变量来源为00规范与流程/设计规范风格/中文路后台系统/tokens.css，部署副本为admin-theme.css中的变量段。

## 后台菜单归属
因本功能主要用于检查课程教学质量、跟进授课反馈，后台入口归属「教务系统 → 教学评价」；功能页面标题为「满意度调查」，其下包含班主任统计、答卷记录、问卷管理三个Tab。班主任服务是评价维度之一，不改变教务业务归属。
