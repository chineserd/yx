# 满意度调查
PRD · V0.9 · 更新日期 2026-10-28

运营编辑并保存课程体验问卷，查看历史答卷；符合条件的用户在App填写收到的问卷。

## 1. 涉及端口 · 菜单 · 功能点
1. 后台菜单｜教务系统 → 教学评价；功能页｜满意度调查 → 班主任统计／答卷记录／问卷管理。
   教学评价菜单内采用三个Tab，顺序为“班主任统计 → 答卷记录 → 问卷管理”，默认进入班主任统计；问卷查看与编辑、答卷详情均使用右侧抽屉。
2. 中文路App｜系统推送／首页邀请 → 问卷填写。
   App以独立问卷页展示完整题干、选项、文本输入与提交；邀请弹窗提供开始评价入口，系统推送可直接进入本次邀请绑定的问卷，见[App页面说明](04-App文字版.md)。通知中心暂不纳入当前产品范围及原型。

## 2. 后台页面及规则
| 位置 | 内容与操作 |
| --- | --- |
| 班主任统计 | 按单份问卷、班主任姓名搜索、日期筛选；展示答卷数、服务满意率；查看答卷携带筛选条件 |
| 问卷管理 | 按问卷名称、发送状态查询；新增、查看、编辑、复制、查看答卷、启用或停用 |
| 问卷详情抽屉 | 查看当前题干、选项、必填性和发送设置；不展示版本号或历史切换入口 |
| 问卷编辑抽屉 | 编辑名称、标题、说明、题型、题干、选项、必填性、题序、人群阈值及每日发送时间；新增或删除题目 |
| 答卷记录 | 按问卷、班主任姓名、学生及提交日期查询；列表直接展示四项评价及一行其他建议，空建议为“-”；默认提交时间倒序 |
| 答卷详情抽屉 | 学生信息、命中对象、填写时题干和答案，只读 |

具体字段统一见[字段核对](02-前后台字段核对.md)。抽屉关闭后保留列表的筛选、页码和每页条数。问卷管理和答卷记录每页默认且最多10条，超过10条分页，不提供更大页容量。

## 3. 班主任统计口径
- 默认首份问卷，按问卷统计全部答卷，不显示版本筛选。班主任为姓名搜索框，支持去除首尾空格后模糊匹配；空值表示全部。统计页和答卷记录一致。
- 按提交时班主任归属分组，无归属显示“未分配班主任”。按答卷数倒序，同数按姓名排序，每页最多10条，不做满意率排名。
- 答卷数包含当前范围全部提交。服务满意率＝满意人数÷可评价人数，保留一位小数，页首汇总与列表均仅显示百分比，不展示分子/分母明细。一般和不满意计入分母，无法评价、未填写、无效及口径不一致答案不计入；无有效分母显示“暂无数据”。表格只展示班主任、答卷数、服务满意率、操作，不展示无法评价数。
- 历史答卷按填写快照中的题目ID及选项归类解析。兼容旧数据时，仅统计与当前服务题题干及题型一致且可识别归类的答案；不一致答案保留在答卷数和明细中，不纳入满意率。此兼容规则不回写原始答案。
- 查看答卷携带问卷、班主任精确归属及日期，保持明细数量与答卷数一致；用户重新输入班主任查询时使用模糊匹配。

## 4. 编辑、历史数据与发送
- 页面不展示版本号、版本筛选和历史版本管理。不设草稿；编辑底部为“取消、保存”，取消或关闭经离开保护后丢弃临时输入。
- 无答卷时可编辑题目、选项、必填和题序；已有答卷时题目与统计口径锁定，可编辑名称、标题、说明及发送配置。保存时再次检查锁定规则，不能只依赖控件禁用。
- 需要改题时使用“复制”建立新的问卷，复制题目和设置，不复制答卷及启用状态；可修改名称，保存后为已停用，运营另行启用。旧问卷需单独停用，不自动替运营停用。
- 新问卷保存后为停用；编辑已有问卷保留启停状态。内部保存内容快照并绑定邀请和答卷，旧邀请、旧答案不会被覆盖；内部标识不作为运营操作字段。
- 保存校验名称、标题、时间、至少一道题；单选至少两个非空且不重复选项。名称/标题100字、说明/题干500字、单项100字、文本答案500字。
- 编辑问卷不展示班主任服务统计配置。系统识别标准班主任服务题（标准题干、单选题且仅出现一次，识别后使用其稳定ID），五档选项自动归类：非常满意/满意→满意，非常不满意/不满意→不满意，一般→一般。未识别到标准题或选项时仅展示答卷数，不让运营手工映射。当前问卷无“无法评价”选项，历史答案仍保留且不进入分母。已存在的内部历史统计映射继续按快照解析。
- 停用停止新邀请、弹窗及提交，保留历史答卷；最终以服务端校验时刻为准。
- 发送对象支持在读用户、复购跟进学生，默认两类，至少一类；命中任一类即可，同一学生按问卷去重。未选类条件禁用；已选在读正式课次数默认3且整数≥1，复购剩余正式课次数默认10且整数≥0，不能为空。
- 每日发送时间使用北京时间；保存后下一匹配时刻生效，不补发错过时刻。配置变化不自动重新邀请已填写用户。

## 5. 调查对象与App行为
已确认对象原文：已上3次正式课的在读用户＋课次数≤10进入复购跟进的学生。两类按并集筛选、重叠不重复邀请；累计正式课次数≥配置次数、剩余正式课次数≤配置上限；正式课统计范围、复购状态映射仍待业务确认。

按学生绑定邀请，由关联账号填写；每学生每问卷完成一次。问卷邀请在课后进入App时触发站内弹窗；距下一节课开课时间≤30分钟不弹；用户当天关闭后当天不再弹，按北京时间自然日判断，次日仍未完成且再次进入App时可再弹。无下一节课时不受课前抑制规则限制。次日提醒复用原邀请，不新建邀请，也不额外重发系统推送。存量学生是否覆盖及多问卷同日触达优先级待业务确认。配置调整不等于新一轮调查。

App单选题不预选，校验邀请绑定快照的必填性；选填空白可提交。失败保留答案并允许重试，同一邀请成功提交只保存一条答卷。身份关系、频控和调度由服务端执行。

App问卷保留完整题干，不展示问卷内部名称、版本、命中条件、重复说明或进度。单学生账号省略姓名；多学生账号展示规则仍待确认。文本题显示500字上限，底部提交固定，题目区域独立滚动。已有填写内容退出需确认；提交成功提示感谢反馈，完成返回学习首页。

## 6. 通知设置与App展示
- 通知设置作为问卷“发送设置”下的子分组，复用发送对象与每日时间，不另建通知菜单或重复配置人群。发送方式仅为“App 内弹窗”和“App 推送”：弹窗按提醒规则展示，推送开关仅控制是否发起推送，实际展示受用户通知权限及设备状态影响。当前不设计独立的 App 通知中心。

- 原型目录依次为“00 弹窗逻辑、01 弹窗场景、02 系统推送、03 邀请弹窗、04 问卷填写”；00用于盘点各业务弹窗并梳理规则，01说明满意度调查弹窗场景，二者仅用于需求梳理与评审，不是学生App页面。小鹿币、新用户及其他历史弹窗场景先列入盘点，具体规则逐类补充，不预设跨场景通用频控。移除预览问卷选择器。系统推送为操作系统通知场景，App内独立通知中心暂缓设计。
- 每日筛选符合条件的用户，先生成绑定问卷版本和学生的邀请；开启系统推送时，将该邀请交给App推送服务。推送时间沿用每日发送时间。
- 后台可配置系统推送开关、通知标题（1—30字）、通知内容（1—100字）；勾选“App 推送”后展开标题、内容和推送说明，关闭时折叠隐藏。关闭时保留已填写文案，再次开启恢复原值；关闭态不校验推送标题和内容，开启时两项必填并校验长度。文案与渠道随问卷版本保存，不含学生姓名、课次等个人信息。通知中心未纳入当前范围。
- App内邀请和系统推送引用同一邀请；重复命中、任务重试不得新建重复邀请。已成功提交后停止后续触达；系统通知可能仍残留在操作系统通知界面，点击时提示已完成。
- 点击通知直接进入邀请绑定的问卷，不先弹首页邀请；本次打开不再重复弹同一邀请。账号关联多个学生时，以邀请绑定学生为评价对象，不根据当前学生随意切换。
- 未登录先完成登录，再校验账号与邀请归属；无访问权提示“当前账号无法查看此问卷”。调查停用、邀请失效提示“本次调查已结束”；已填写提示“您已完成本次评价”。
- 用户未开启系统通知、设备标识无效或推送失败，不阻断App内邀请；不强制授权通知。用户进入App首页或课程结束后回到前台时检查有效邀请；仅课程已结束、邀请未完成、当天未关闭且距离下一节课开课时间大于30分钟时展示；距离开课时间恰好30分钟也不弹。当天点击关闭或“暂不评价”后，当天不再展示；按北京时间自然日判断，次日仍未完成且再次进入App时恢复提醒。无下一节课时不受课前30分钟规则限制。课堂中不弹。
- App前台不同时叠加系统横幅与站内弹窗；课堂、作业或支付等不可打断场景暂缓站内弹窗，离开后回到首页再按上述规则检查。客户端需提供课程开始/结束及首页、前后台切换事件；系统通知权限与具体生命周期事件由客户端联调。
- 每份邀请系统推送一次；通道重试复用同一发送任务标识，填写完成或停用后停止重试。次日重提醒仅适用于App内弹窗，不重复发送系统推送。跨问卷频控、失败重试间隔及有效期仍需运营与研发确认，不以每日任务自动重复催填。

## 8. 待确认事项
填写角色、课次及复购状态口径、上线存量覆盖、多问卷同时符合时的频控；课程开始/结束时间字段及跨端关闭日期记录由研发确认接入来源。App展示不含内部版本及筛选条件。接口及实现边界见[接口说明](03-接口说明.md)。
